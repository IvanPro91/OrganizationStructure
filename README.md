# OrganizationStructure
Проект для управления организационной структурой (дерево подразделений и сотрудников).

### Установка и запуск проекта
Данное руководство поможет настроить окружение с нуля: установить Python 3.14, Git, Poetry, клонировать репозиторий и установить все зависимости.

#### 1. Установка Python 3.14
Windows
Перейдите на официальный сайт Python и скачайте установщик Python 3.14 (например, Windows installer (64-bit)).

Запустите скачанный файл.

Важно! В начале установки обязательно отметьте галочку Add Python to PATH.

Нажмите Install Now и дождитесь завершения установки.

macOS / Linux
Рекомендуется использовать пакетный менеджер (например, brew для macOS или apt для Ubuntu) либо скачать установщик с официального сайта. Убедитесь, что версия Python 3.14 доступна в системе.

#### 2. Установка Git
Windows
Скачайте установщик с официального сайта Git и запустите его. При установке можно оставить все параметры по умолчанию.

macOS
```
brew install git
```

Linux (Ubuntu/Debian)
```
sudo apt update && sudo apt install git
```

#### 3. Клонирование репозитория
Откройте терминал (командную строку) и перейдите в папку, где будет храниться проект:
```
cd /путь/к/вашим/проектам
```

Выполните клонирование:
```
git clone https://github.com/IvanPro91/OrganizationStructure.git
```

Перейдите в папку проекта:
```
cd OrganizationStructure
```

#### 4. Установка Poetry
Poetry — инструмент для управления зависимостями и виртуальным окружением. Установите его с помощью официального скрипта.

Выполните в терминале:
```
curl -sSL https://install.python-poetry.org | python3 -
```
Проверьте установку:
```
poetry --version
```
#### 5. Установка зависимостей проекта
Убедитесь, что вы находитесь в папке проекта (OrganizationStructure). Затем выполните:
```
poetry install
```
Эта команда создаст виртуальное окружение с Python 3.14 и установит все зависимости, указанные в pyproject.toml и poetry.lock.

#### 6. Миграции
Выполните создание и применение миграций базы данных:
```
poetry run python manage.py makemigrations
poetry run python manage.py migrate
```
#### 7. Запуск проекта
```
poetry run python manage.py runserver
```
После запуска проект будет доступен по адресу http://127.0.0.1:8000/.

### Обновление проекта из Git
Когда необходимо получить последние изменения из удалённого репозитория (например, после обновления кода другими разработчиками), выполните следующие шаги.

#### 1. Перейдите в директорию проекта
```
cd OrganizationStructure
```
#### 2. Проверьте текущее состояние репозитория
```
git status
```
Убедитесь, что у вас нет незакоммиченных изменений, которые могут помешать обновлению. Если есть, сначала сохраните их (сделайте коммит или stash).

#### 3. Получите изменения с удалённого репозитория
```
git fetch origin
```
#### 4. Обновите локальную ветку
Если вы работаете в ветке main (или master — уточните основную ветку проекта):
```
git pull origin main
```
Или просто:
```
git pull
```
Git автоматически попытается слить удалённые изменения с вашей локальной веткой.

#### 5. Разрешение конфликтов (если они возникли)
Если при слиянии возникли конфликты, Git сообщит об этом. Откройте конфликтующие файлы, разрешите конфликты вручную, затем выполните:
```
git add .
git commit -m "Resolved merge conflicts"
```
#### 6. Обновите зависимости
Если в pyproject.toml или poetry.lock были изменения (появились новые пакеты или обновились версии), выполните:
```
poetry install
```
#### 7. Примените новые миграции
Если в коде появились новые миграции базы данных, выполните:

poetry run python manage.py migrate
#### 8. Перезапустите сервер (если он был запущен)
Остановите сервер (Ctrl+C) и запустите снова:

poetry run python manage.py runserver
### Создание суперпользователя
Для доступа в административную панель создайте суперпользователя:

poetry run python manage.py createsuperuser
Или с предустановленным именем:
```
poetry run python manage.py createsuperuser --username admin
```
После успешного создания перейдите по адресу http://127.0.0.1:8000/admin/, введите данные суперпользователя и управляйте проектом.
