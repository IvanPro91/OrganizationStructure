# Установка и запуск проекта OrganizationStructure

Данное руководство поможет вам настроить окружение с нуля: установить Python 3.11, Git, Poetry, клонировать репозиторий и установить все зависимости проекта.

## 1. Установка Python 3.11

Выберите инструкцию для вашей операционной системы.

### Windows
1. Перейдите на [официальный сайт Python](https://www.python.org/downloads/windows/) и скачайте установщик Python 3.11 (например, `Windows installer (64-bit)`).
2. Запустите скачанный файл.
3. **Важно!** В самом начале установки **обязательно отметьте галочку** `Add Python to PATH`.
4. Нажмите `Install Now` и дождитесь завершения установки.


## 2. Установка Git
Windows
Скачайте установщик с официального сайта Git и запустите его. 
При установке можно оставить все параметры по умолчанию.

## 3. Клонирование репозитория
Откройте терминал (командную строку) и перейдите в папку, где будет храниться проект:

`cd /путь/к/вашим/проектам`
Выполните клонирование:

`git clone https://github.com/IvanPro91/OrganizationStructure.git`
Перейдите в папку проекта:

`cd OrganizationStructure`

## 4. Установка Poetry
Poetry — это инструмент для управления зависимостями и виртуальным окружением. Установите его с помощью официального скрипта.

Выполните в терминале:

`curl -sSL https://install.python-poetry.org | python3 -`

Проверьте установку:
`poetry --version`

## 5. Установка зависимостей проекта
Убедитесь, что вы находитесь в папке проекта (OrganizationStructure). Затем выполните:
`poetry install`

Эта команда создаст виртуальное окружение с Python 3.11 и установит все необходимые зависимости, указанные в pyproject.toml и poetry.lock.

## 6. Миграции

Скорее всего, команды будут такими:
`
poetry run python manage.py makemigrations
poetry run python manage.py migrate
`

## 7. Запуск проекта

После установки зависимостей ознакомьтесь с файлом README.md внутри проекта — в нём могут быть дополнительные инструкции по запуску и настройке.

`poetry run python main.py`
